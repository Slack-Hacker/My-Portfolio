[![React](https://img.shields.io/badge/React-18-61DAFB.svg)](https://react.dev/)

A modern, responsive **Full-Stack Developer Portfolio Web Application** showcasing projects, technical skills, interactive contact forms, experience timelines, and API integration.

Built by **Slack-Hacker**.

---

## 🌟 Key Features

- **💼 Dynamic Project Showcase**: Interactive project cards with technology filters, GitHub repository links, and live demonstration links.
- **⚡ Modern Responsive UI**: React-powered user interface built with modern CSS flexbox/grid, animations, and dark mode styling.
- **📩 Interactive Contact Form**: Backend API integration for contact messaging, email forwarding, and input validation.
- **📄 Postman Collection & API Docs**: Includes pre-configured `postman_collection.json` for API endpoint testing and backend interaction.

## 📁 Repository Structure


## 🚀 Quick Start

### 1. Clone the Repository

```bash
git clone https://github.com/Slack-Hacker/My-Portfolio.git
cd My-Portfolio
```

### 2. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### 3. Backend Setup

```bash
cd ../backend
npm install
npm start
```

Open **`http://localhost:3000`** in your browser.
